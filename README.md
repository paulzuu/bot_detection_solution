# Классификация трафика по событиям cookie

Готовый файл для отправки - `submission.csv`: 4 909 строк, колонки `cookie_id` и `score`.
Основной разбор с кодом и сохранёнными результатами находится в `solution.ipynb`.
Краткое описание подхода - в `REPORT.md`.

На финальном временном holdout результат составляет **0,6512 по Precision при Recall >= 70%**.
У baseline на двух счётчиках - 0,0931. Качество скрытого test неизвестно.

## Запуск

Проверено на **Python 3.12.14**, CPU, четырёх потоках. GPU не требуется.
Исходные данные уже находятся в папке `data/`. После установки зависимостей обучение и предсказание работают локально, без сетевых запросов.

Из папки проекта в Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py --verify
```

В Linux или macOS:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py --verify
```

Команда заново читает исходные CSV, строит признаки, обучает выбранную модель и перезаписывает `submission.csv`.
Флаг `--verify` проверяет побайтовое совпадение с приложенным результатом по SHA-256.
Он не участвует в расчёте предсказаний. Для другой папки данных или выходного файла доступны
`--data-dir PATH` и `--output PATH`.

В Jupyter или VS Code откройте `solution.ipynb` и выберите созданное окружение.
Если его нет в списке ядер, зарегистрируйте его:

```powershell
.\.venv\Scripts\python.exe -m ipykernel install --user --name bot-detection --display-name "Bot detection (Python 3.12)"
```

Ноутбук запускается из папки проекта. Выполните все ячейки сверху вниз: он повторяет сравнение моделей,
финальную проверку и создание CSV. Сохранённые таблицы и графики можно прочитать без запуска.
Самая долгая часть — построение признаков. Полный проход ноутбука занимает несколько минут;
время конкретного прогона записано в последней вычисляемой ячейке.

## Что находится в проекте

| Файл | Назначение |
|---|---|
| `solution.ipynb` | Полный ход решения, сравнение моделей, ошибки и результаты |
| `features.py` | Фильтрация окон, очистка и построение признаков |
| `training.py` | Модели, временные разбиения, оценка и проверки submission |
| `run.py` | Повторное получение CSV без Jupyter |
| `metric.py` | Неизменённая официальная метрика из задания |
| `model_config.json` | Итоговая конфигурация, зафиксированная до holdout |
| `experiment_configs.json`, `ensemble_configs.json` | Воспроизводимые настройки сравнений |
| `requirements.txt` | Версии библиотек |
| `test_solution.py` | Проверки границ окна, дубликатов, порядка событий, пустых историй, метрики и формата CSV |
| `results/` | Метрики, предсказания на размеченной проверке, разбор ошибок и важность признаков |
| `figures/` | Графики, показанные в ноутбуке |
| `reference_submission.sha256` | Контрольная сумма отправляемого CSV |
| `data/` | Исходные train, test и события без изменений |

Проверки запускаются командой `python -m unittest -v test_solution` в созданном окружении.
Они не требуют переобучения модели.

Использованы open-source библиотеки pandas, NumPy, SciPy, scikit-learn, CatBoost и Matplotlib.
